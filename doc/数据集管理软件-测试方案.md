# 数据集管理软件 - 界面自动化测试方案

## 1. 概述

### 1.1 编写目的

本测试方案针对数据集管理软件（DatasetMan）的 Web 前端界面进行系统性自动化测试，覆盖登录、数据源管理、数据集管理、用户管理、权限管理、函数管理、Transform 编排与任务管理、评价准则、质量测评、修改密码等全部功能模块。通过 Selenium WebDriver 模拟用户真实操作（点击、输入、选择、提交等），验证界面元素完整性、交互逻辑正确性、前端校验有效性以及边界情况处理。

### 1.2 测试范围

| 模块 | 前端页面/组件 | 测试类 | 用例数 |
|------|--------------|---------|-------|
| 登录模块 | login.html | LoginUiTest.java | 7 |
| 数据源管理 | data-source-list.html, register-embedded.html | DataSourceUiTest.java | 17 |
| 数据集管理 | dataset-dialog.html | DatasetUiTest.java | 8 |
| 用户管理 | user-management.html | UserPermissionUiTest.java | 12 |
| 权限管理 | permission-management.html | UserPermissionUiTest.java | 5 |
| 修改密码 | change-password.html | UserPermissionUiTest.java | 6 |
| Transform 托管 | transform-management.html | FunctionUiTest.java | 7 |
| UDF 托管 | udf-management.html | FunctionUiTest.java | 4 |
| Transform 编排 | transform-compare.html | TransformUiTest.java | 5 |
| Transform 任务 | transform-job (动态加载) | TransformUiTest.java | 6 |
| 评价准则 | evaluation-criteria.html | QualityUiTest.java | 8 |
| 质量测评 | quality-assessment.html | QualityUiTest.java | 6 |
| **合计** | | | **90** |

### 1.3 测试环境

- **操作系统**: Windows / Linux
- **JDK**: 1.8
- **浏览器**: Google Chrome（通过 WebDriverManager 自动管理 ChromeDriver）
- **测试框架**: JUnit 5 + Selenium WebDriver 4
- **设计模式**: Page Object Model
- **构建工具**: Maven
- **应用服务器**: 数据集管理平台（默认 http://localhost:8080）

### 1.4 测试策略

- **页面元素验证**: 验证表单字段、按钮、表格表头、下拉选项等元素存在且可见
- **正常流程测试**: 模拟用户完成登录、注册数据源、创建数据集、新增用户等完整操作流程，提交后等待接口响应并验证结果
- **接口响应验证**: 表单提交后通过等待 Toast 提示（成功/失败）或弹窗关闭来确认接口已返回，而非固定等待时间
- **前端校验测试**: 验证空值必填、密码不一致、非法端口等前端校验逻辑
- **取消操作测试**: 验证各模块弹窗/表单的取消按钮能正确关闭界面
- **筛选与重置测试**: 验证列表页筛选查询和重置功能，查询后等待表格刷新
- **边界情况测试**: 超长输入、特殊字符（XSS 防护）、短密码等边界条件
- **导航测试**: 验证顶部导航栏下拉菜单能正确切换功能页面

## 4. 测试执行

### 4.1 环境准备

Selenium 和 WebDriverManager 依赖已在 `datasetman-server/pom.xml` 中配置，无需额外安装。

### 4.2 启动应用服务器

确保数据集管理平台服务已启动，默认监听 `http://localhost:8080`。

### 4.3 执行命令

```bash
# 运行全部UI测试
cd datasetman-server
mvn test -Dtest="com.tsinghua.ui.**"

# 运行特定模块测试
mvn test -Dtest="com.tsinghua.ui.LoginUiTest"           # 登录模块
mvn test -Dtest="com.tsinghua.ui.DataSourceUiTest"      # 数据源管理
mvn test -Dtest="com.tsinghua.ui.DatasetUiTest"         # 数据集管理
mvn test -Dtest="com.tsinghua.ui.UserPermissionUiTest"  # 用户管理、权限管理与修改密码
mvn test -Dtest="com.tsinghua.ui.FunctionUiTest"        # 函数管理
mvn test -Dtest="com.tsinghua.ui.TransformUiTest"       # Transform 编排与任务
mvn test -Dtest="com.tsinghua.ui.QualityUiTest"         # 评价准则与质量测评

# 运行单个测试方法
mvn test -Dtest="com.tsinghua.ui.LoginUiTest#testLoginSuccess"
```

### 4.4 环境变量配置（可选）

| 变量名 | 默认值 | 说明 |
|--------|-------|------|
| TEST_BASE_URL | http://localhost:8080 | 应用服务器地址 |
| TEST_USER | test | 测试用户名 |
| TEST_PASS | test123 | 测试密码 |

### 4.5 测试报告

测试完成后可通过以下方式查看报告：

**Surefire HTML 报告**（基础）：
- 路径：`datasetman-server/target/site/surefire-report.html`
- 内容：测试通过率、失败用例详情、执行时间统计

**Allure 文档式报告**（高级，含图表与截图）：
```bash
# 运行测试并生成Allure结果数据
cd datasetman-server
mvn test -Dtest="com.tsinghua.ui.**"

# 生成Allure HTML报告
mvn allure:report

# 或直接在浏览器中打开已生成的报告
# 路径：datasetman-server/target/allure-report/index.html
```
Allure 报告包含：
- 测试概览仪表盘（通过率饼图、趋势图）
- 按模块分组的测试结果
- 每个用例的详细步骤与截图
- 失败用例的错误堆栈与现场截图
- 执行时间统计与历史趋势

**XML 报告**（CI/CD 集成用）：
- 路径：`datasetman-server/target/surefire-reports/`

### 4.6 持续集成

建议将测试集成到 CI/CD 流水线中，取消 `UiTestBase.java` 中 `--headless=new` 的注释以在无头模式下运行，每次代码提交自动执行测试，确保界面质量。
